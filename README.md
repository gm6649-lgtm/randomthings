# randomthings

A collection of small tools and experiments.

## Projects

### [Chess PGN Analyzer](chess-pgn-analyzer/)

A browser-based chess game analyzer powered by **Stockfish** (depth 16).

Paste any PGN, click **Analyze**, and get per-move evaluations with
chess.com-style classifications: brilliant, great, best, excellent, good,
inaccuracy, mistake, and blunder.

See [chess-pgn-analyzer/README.md](chess-pgn-analyzer/README.md) for full
instructions.
